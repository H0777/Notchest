٠١البداية

النسخة الحالية 0.5 ولا يوجد إصدار موقّع بعد، فالبناء من المصدر يستغرق دقيقة واحدة تقريبًا.

$ git clone https://github.com/H0777/Notchest.git
$ cd Notchest
$ ./build.sh     #→ dist/Notchest.app
$ ./check.sh     #→ 34 فحصًا آليًا

افتح dist/Notchest.app مرة واحدة لتظهر الجزيرة حول النوتش على الشاشة التي تختارها. انقرها لفتح صندوق الأدوات. المتطلبات: macOS 13 فما أحدث (Apple Silicon)، وXcode 26 أو أدوات سطر الأوامر مع SDK macOS 26 للبناء.

أول تشغيل على macOS. نسخة التطوير الحالية موقّعة محليًا ولم تحصل بعد على توقيع Developer ID أو تصديق Apple. حمّل DMG أو ZIP من الإصدار الرسمي وانقل Notchest إلى Applications. إذا كنت تثق بالمصدر، حاول فتحه، ثم انتقل إلى إعدادات النظام ← الخصوصية والأمان ← الأمان ← فتح على أي حال بجانب Notchest، وأكّد الفتح. إذا لم يظهر الزر، حاول فتح التطبيق مرة أخرى. تعليمات Apple الرسمية.

٠٢الأدوات اليومية

مؤقّت التركيز والساعة

جلسات تركيز موقوتة مع تقدم مباشر على الجزيرة.

  1. افتح الجزيرة واختر أداة التركيز.
  2. حدّد المدة وابدأ؛ اطوِ الجزيرة وواصل عملك.
  3. يبقى التقدم والاكتمال ظاهرين على النوتش.

الملاحظات

مسودة سريعة تبقى بعد إعادة التشغيل.

  1. افتح أداة الملاحظات واكتب.
  2. يُحفظ النص محليًا ويُستعاد في التشغيل التالي.

سجل الحافظة (اختياري)

آخر المنسوخات، محفوظة على قرصك فقط.

  1. فعّل سجل الحافظة من الإعدادات.
  2. انسخ كالمعتاد؛ تظهر آخر العناصر في الأداة.
  3. العناصر الموسومة كخاصة من النظام تُستثنى.

رف الملفات

ملفات ومجلدات في متناولك دون فوضى على سطح المكتب.

  1. اسحب الملفات إلى رف الجزيرة.
  2. تُحفظ مراجع محلية، ويُحترم نقل الملف أو حذفه.

٠٣مساحة المطوّر

الطرفية المدمجة

طرفية تفاعلية حقيقية (SwiftTerm) داخل الجزيرة.

  1. افتح قسم المطوّر واختر الطرفية.
  2. اكتب الأوامر؛ الجلسة تبقى عند التنقل بين الأقسام.

مشغّل الأوامر

أوامر zsh غير تفاعلية مع التقاط الخرج وإمكانية الإيقاف.

  1. اختر مجلد العمل.
  2. اكتب الأمر واضغط تشغيل؛ استخدم إيقاف للمقاطعة.

أدوات الكود

JSON وترميزات ودوال تجزئة ووقت — بنقرة واحدة لكل منها.

  1. الصق النص ثم اضغط JSON أو Minify أو Base64 أو URL أو SHA-256 أو UUID أو Epoch أو Regex.
  2. زر التبديل يعيد النتيجة مدخلًا جديدًا.

Git وطلبات السحب

حالة أي مجلد، وطلبات السحب عبر GitHub CLI.

  1. لطلبات السحب ثبّت GitHub CLI: brew install gh ثم gh auth login.
  2. اختر مجلد مشروعك في قسم Git.
  3. حدّث لرؤية الفرع والتغييرات والالتزامات؛ انتقل إلى GitHub PR لطلبات السحب.
بدون gh مثبتًا ومسجّلًا، يخبرك القسم بذلك بوضوح بدل الفشل الصامت.

المقتطفات

الأوامر والقوالب التي تعيد كتابتها دائمًا.

  1. أضف مقتطفًا باسم ونص.
  2. انقره في أي وقت لنسخه إلى الحافظة.

واجهة النشاط (اختيارية)

دع سكربتاتك ترسل تقدم البناء والمهام إلى الجزيرة.

  1. فعّل واجهة النشاط من الإعدادات؛ يُنشأ رمز وصول متغير.
  2. أرسل الأحداث إلى النقطة المحلية من سكربتاتك أو خطافاتك.
  3. يظهر التقدم والاكتمال كنشاط على الجزيرة.
الواجهة محلية فقط وتبقى معطلة حتى تفعّلها.

٠٤استخدام الذكاء الاصطناعي دون تجسس

القراءة المحلية

الرموز من سجلات Codex وClaude الموجودة على جهازك.

  1. استخدم Codex أو Claude CLI كالمعتاد؛ لا إعداد مطلوب.
  2. افتح قسم الاستهلاك — رموز اليوم والأسبوع وإعادة استخدام الكاش والنشاط الأسبوعي.
  3. إن كانت سجلاتك في مكان آخر فوجّه الأداة إلى ذلك المجلد.

حدود حساب Codex الحيّة

نوافذ حدود الحساب الحالية، عند الطلب.

  1. ثبّت Codex CLI وسجّل الدخول.
  2. اضغط «حدود الحساب الحيّة» في قسم الاستهلاك.
  3. تظهر النوافذ ومواعيد التجديد ووقت القراءة في لوحة مستقلة لا تشترط وجود سجلات محلية.
لا تُستخرج نصوص المحادثات ولا مفاتيح الدخول. الرموز المحلية ليست فاتورة.

٠٥الأدوات اليومية المتقدمة

الطقس

الأحوال والتوقعات (Open-Meteo).

  1. افتح أداة الطقس وابحث عن مدينتك.
  2. يظهر وقت آخر تحديث دائمًا؛ أعد المحاولة عند أخطاء الشبكة.

الترجمة

ترجمة Apple على الجهاز، macOS 15+.

  1. افتح أداة الترجمة على macOS 15 فما أحدث.
  2. نزّل زوج اللغات عندما يطلب macOS ذلك.
  3. على macOS 13–14 تشرح الأداة أن النظام لا يدعمها.

الأسهم

علامات عبر Alpha Vantage بمفتاحك الخاص.

  1. أنشئ مفتاح Alpha Vantage مجانيًا والصقه في الأداة؛ يُحفظ في Keychain.
  2. أضف الرموز وحدّث؛ يظهر تاريخ السعر.
  3. التنبيهات تقارن السعر عند التحديث — قد يكون آخر إغلاق لا لحظيًا.

الموسيقى والكلمات

تحكم وغلاف وكلمات لـ Apple Music أو Spotify.

  1. شغّل Apple Music أو Spotify وشغّل مقطعًا.
  2. اسمح بالأتمتة عند طلب macOS؛ يظهر التحكم والغلاف.
  3. اطلب الكلمات (LRCLIB) — متزامنة عند توفرها أو نصية.

٠٦المراقبة — كلها اختيارية

كل مراقب يطلب إذن macOS الخاص به وتبقى معطلة حتى تفعّلها.

التنزيلات والأقراص

  1. فعّل مراقبة التنزيلات لتصلك إشارة «ملف جديد» في مجلد التنزيلات.
  2. تظهر الأقراص القابلة للإزالة وتختفي عند وصله وفصلها.

مرآة الكاميرا

  1. افتح أداة الكاميرا واسمح بالوصول.
  2. تُستخدم الكاميرا فقط أثناء فتح المرآة.

التقويم والتذكيرات

  1. اربط التقويم لرؤية الأحداث القادمة.
  2. لا تُنشأ التذكيرات إلا عندما تضيف واحدة بنفسك.

Caps Lock

  1. فعّله من الإعدادات؛ تعكس الجزيرة حالة المفتاح.

٠٧الإعدادات

الجزيرة

  1. الحجم: أصغر وافتراضي وأكبر مقاس مدعوم.
  2. الحركة: تشغيل/إيقاف مع التحكم بالمدة؛ يُحترم تقليل الحركة دائمًا.
  3. الشاشة: اختر الشاشة التي تحمل الجزيرة.

المظهر واللغة

  1. ألوان التمييز، مع حفظ اختيارك المخصص.
  2. اللغة: الإنجليزية افتراضية، وعربية كاملة بتخطيط من اليمين لليسار.
  3. Liquid Glass على macOS 26+ وخامة النظام على الأقدم.

بدء التشغيل

  1. فعّل «التشغيل عند الدخول»؛ يستخدم آلية عناصر الدخول القياسية في macOS.
