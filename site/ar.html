معلومات مفيدة

التفاصيل التي تهمك.

ما الأجهزة والأنظمة المطلوبة؟

الحزمة مخصصة لـApple Silicon. يستهدف المصدر macOS 13+؛ الترجمة تحتاج 15+ وLiquid Glass يحتاج 26+. اختبار الأنظمة الأقدم وIntel ما زال ضمن خطة العمل.

هل تحتاج كل أداة إلى حساب؟

لا. الملاحظات والتركيز وتحويلات الكود والأدوات المحلية تعمل دون حساب. للأدوات المتصلة مثل GitHub وحدود الحساب والأسهم والموسيقى متطلبات إعداد منفصلة.

هل هذه صور حقيقية من التطبيق؟

نعم. هي لقطات لواجهة SwiftUI وAppKit أثناء التشغيل في نسخة توثيق منفصلة. الملاحظات والاستخدام وقراءات النظام والموسيقى وأحداث المهام أمثلة موسومة بوضوح. لم تُستخدم حسابات شخصية أو الكاميرا أو الحافظة الخاصة.

هل يمكنني بناءه بنفسي؟

بالتأكيد. المشروع بترخيص MIT. استخدم Xcode 26+ أو أدوات Swift مع SDK macOS 26، واتبع تعليمات البناء في المستودع. تعليمات البناء ↗
