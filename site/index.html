GOOD TO KNOW

The details, without the noise.

Which Mac and macOS versions?

The packaged build is for Apple Silicon. Source targets macOS 13+, with Apple Translation on 15+ and Liquid Glass on 26+. Earlier-system and Intel validation remain on the roadmap.

Does everything need an account?

No. Notes, focus, code transforms, and other local tools work without one. GitHub, account limits, stocks, music, and other connected tools have their own setup requirements.

Are these screenshots real?

Yes. They are captures of the running SwiftUI/AppKit interface in an isolated documentation build. Example notes, usage, system readings, track details, and task events are labeled sample data. No personal accounts, camera, or private clipboard were used.

Can I build it myself?

Absolutely. The project is MIT licensed. Use Xcode 26+ or Swift tools with the macOS 26 SDK, then follow the repository build instructions. Build instructions ↗
