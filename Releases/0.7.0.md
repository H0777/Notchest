Notchest 0.7.0 brings system notifications, a fully transparent glass island, first-run setup, and smarter AI-usage tracking.

### What's new

- **System notifications (opt-in):** focus-session completion, new files in Downloads, connected drives, and stock price alerts — through the standard macOS notification center, following the app language. Enable once in Settings; island toasts and the activity feed keep working independently.
- **One glass island, collapsed or expanded:** the slim collapsed bar now shares the same transparent glass surface as the expanded island instead of rendering as a solid black block, with a slightly stronger top scrim so status text stays readable. Reduce-transparency and increased-contrast keep solid fallbacks.
- **First-run setup:** connection checks and Developer/Focus/Everyday presets, with persistent, reorderable home cards and an adjustable background-transparency control.
- **Sharper AI usage tracking:** side-by-side local Codex/Claude summaries, optional 80%/95% usage alerts, automatic five-second refreshes, and opt-in live Codex limit refreshes that keep the last snapshot visibly marked when stale.
- **Opt-in agent hooks and project tracking:** native hooks for task states with metadata-only local delivery, plus GitHub Actions tracking for a selected project.
- **Update awareness:** periodic stable-release checks with official download-page links.

### Under the hood

- A large-log memory leak is fixed: peak sampled RSS during a big local scan dropped from ~536 MiB to ~103 MiB.
- Appended JSONL records are read incrementally with retry and rebuild-after-truncation semantics.
- The site version and download links follow the app bundle metadata, and pages are validated before every deployment.

### Install or update

Download **Notchest-0.7.0.dmg**, open it, and drag Notchest into Applications. If an older copy is running, quit it from the menu bar before replacing it, then open the new copy. Preferences stay under the same app identifier. A portable ZIP is also available.

The packaged build is for **Apple Silicon**. Source targets macOS 13+; Apple Translation needs macOS 15+, and native Liquid Glass needs macOS 26+. Older-system and Intel validation remain planned.

### If macOS blocks first launch

The build is not yet Developer-ID signed or notarized, so macOS asks for a one-time confirmation: right-click → **Open** (macOS 13–14), or **System Settings → Privacy & Security → Open Anyway** (macOS 15+).

A SHA-256 checksum file is included with the release assets.
