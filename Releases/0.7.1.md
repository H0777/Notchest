Notchest 0.7.1 makes the portable ZIP the easiest way to install for first-time users.

### What's new

- **A bilingual guide inside the ZIP:** every ZIP release now carries a `READ-ME-FIRST.txt` beside the app — Arabic and English, three install steps, the exact one-time macOS approval (Open Anyway) in the easiest order, an optional Terminal alternative, and why the warning appears. No more guessing after extraction.
- **The ZIP is the direct path:** extract, double-click the app, approve once. The DMG with its branded drag-to-Applications window remains for those who prefer the familiar Mac flow.
- Packaging now verifies the guide ships inside every ZIP before publication.

### Install or update

From Releases, download **Notchest-0.7.1.zip** for the quickest route: extract it, read `READ-ME-FIRST.txt`, and follow its three steps — or pick **Notchest-0.7.1.dmg** for the classic drag-to-Applications window. If an older copy is running, quit it from the menu bar before replacing it.

### If macOS blocks first launch

The build is not yet Developer-ID signed or notarized, so macOS asks for a one-time confirmation: right-click → **Open** (macOS 13–14), or **System Settings → Privacy & Security → Open Anyway** (macOS 15+). The guide inside the ZIP walks through it step by step, in Arabic and English.

A SHA-256 checksum file is included with the release assets.
