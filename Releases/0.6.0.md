Notchest 0.6.0 brings a more colorful identity, a polished Mac installation window, and clearer language handling.

### What's improved

- **Aurora Orbit icon:** vivid turquoise, violet and pink glass with a warm coral center, with dedicated artwork for every macOS icon size.
- **A new installation experience:** a Retina drag-to-Applications window with a matching background, clear direction arrow and English/Arabic instructions.
- **Consistent interface language:** service messages, weather, stocks, translation, notifications and developer-tool guidance follow the language selected in the app.
- **Clearer live Codex limits:** account limits stay visible when local usage logs are missing or paused.
- **Developer tool fixes:** find GitHub CLI installed in `~/.local/bin` when opening from Finder; Regex and text-count summaries now follow the app language.
- **More reliable packaging:** the mounted DMG and extracted ZIP are checked before publication, including the app signature, executable permissions, install destination and package contents. A SHA-256 checksum file is included.

![The new Notchest installer in Finder](https://raw.githubusercontent.com/H0777/Notchest/v0.6.0/Brand/Installer/preview.jpg)

### Install or update

Download **Notchest-0.6.0.dmg**, open it, and drag Notchest into Applications. If an older copy is running, quit it from the menu bar before replacing it, then open the new copy. Preferences stay under the same app identifier. A portable ZIP is also available.

The packaged build is for **Apple Silicon**. Source targets macOS 13+; Apple Translation needs macOS 15+, and native Liquid Glass navigation needs macOS 26+. Older-system and Intel validation remain planned.

This development build uses ad-hoc signing and is not yet Developer-ID signed or Apple-notarized. If macOS blocks first launch, use its standard Open Anyway flow in System Settings → Privacy & Security.

### بالعربية

يتضمن الإصدار **0.6.0** أيقونة Aurora Orbit بألوان نابضة، ونافذة تثبيت خاصة تدعم شاشات Retina، وتحسين رسائل الأدوات لتتبع لغة الواجهة المختارة، وإظهار حدود Codex الحية حتى عند إيقاف قراءة السجلات المحلية.

للتحديث: أنهِ النسخة القديمة من شريط القوائم، وافتح ملف DMG، واسحب Notchest إلى Applications واستبدل النسخة السابقة، ثم افتحه. يُستخدم معرّف التطبيق نفسه للحفاظ على الإعدادات. الحزمة مخصصة لـ **Apple Silicon**، وهي إصدار تطوير لم يُصدّق بعد من Apple.
