Notchest 0.7.2 ships the bilingual first-open guide inside **both** packages — the DMG and the ZIP.

### What's new

- **The DMG now explains itself:** opening the disk image shows the app, the Applications destination, and a `READ-ME-FIRST.txt` guide positioned between them — Arabic and English, three install steps, the exact one-time macOS approval (Open Anyway), an optional Terminal alternative, and why the warning appears.
- **The ZIP keeps its guide:** extraction shows the same `READ-ME-FIRST.txt` beside the app.
- The installer validator now asserts the guide ships inside the DMG (presence, size, and icon position) alongside the app signature, executable permissions, and layout checks it already performs.

### Install or update — pick your path

**ZIP (quickest):** download `Notchest-0.7.2.zip`, extract it, open `READ-ME-FIRST.txt`, follow its three steps — extract, (optionally) move to Applications, approve once.

**DMG (classic Mac flow):** download `Notchest-0.7.2.dmg`, open it, and the installer window shows everything: drag Notchest onto Applications, then follow the guide icon's one-time approval steps.

Either way, if macOS blocks the first launch: right-click → **Open** (macOS 13–14), or **System Settings → Privacy & Security → Open Anyway** (macOS 15+). Once approved, the warning never returns for that version. If an older copy is running, quit it from the menu bar before replacing it.

A SHA-256 checksum file is included with the release assets.
