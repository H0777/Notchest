# هوية Notchest 0.5

Notchest مساحة صغيرة للأدوات اليومية والعمل. رمزه مدار مائل يحتضن نواة؛ حلقة أدوات تحيط بعملك أعلى الشاشة. الشعار أصلي مرسوم بالكود، والأيقونة مصممة لتنسجم مع الماك.

## الملفات

- `Notchest-AppIcon.png`: الأيقونة بدقة 1024×1024 مع خلفية خارجية شفافة.
- `Notchest-Mark.svg`: الشعار المتجهي الملون، قابل للتعديل والتكبير.
- `Notchest-Mark-Mono.svg`: الشعار الأحادي للطباعة والاستخدام الصغير.
- `../Resources/Notchest.icns`: الأيقونة متعددة الأحجام المستخدمة في حزمة التطبيق.
- `../Scripts/generate-brand.swift`: البناء المتجهي للأيقونة؛ يولّد أحجام macOS من 16 إلى 1024.

لإعادة توليد الأيقونة على الماك:

```sh
swift Scripts/generate-brand.swift
```

ثم أعد إنشاء التطبيق باستخدام `./build.sh`.

## لغة الواجهة

- Liquid Glass الأصلي لعناصر التنقل والتحكم على macOS 26 فما أحدث.
- خامة نظام بديلة على macOS 13–15.
- خلفية النافذة تستخدم خامة macOS الفعلية، وبطاقات المحتوى أهدأ بصريًا.
- عند تفعيل تقليل الشفافية أو زيادة التباين تصبح الأسطح أكثر صلابة ووضوحًا.
- الحركة قصيرة ومحدودة للتنقل والضغط والتحويم، وتراعي تقليل الحركة وإعدادات حركة الجزيرة.
- الجزيرة المصغرة تبقى سوداء لتنسجم مع فتحة الكاميرا.

طبقة التصميم المشتركة في `Sources/Notchest/NotchestDesign.swift`. مرجع الاستخدام: [Adopting Liquid Glass — Apple](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass).

تجمع الخلفية الأزرق السماوي والبنفسجي والوردي، بينما تحتفظ النصوص بطبقة واضحة للقراءة. شكل الجزيرة يتصل بأعلى الشاشة عبر انحناءات داخلية، مع الحفاظ على انحناءات أسفلها. مسار الشكل مشترك بين SwiftUI وقناع نافذة الماك في `IslandSizing.swift` لتطابق القص والحواف. الإنجليزية هي اللغة الافتراضية، والعربية خيار إضافي محفوظ.

أزيل خط الحد الخارجي وظل نافذة النظام، وتُقص خامة الضبابية نفسها إلى مسار الجزيرة لمنع ظهور إطار مستطيل شفاف حولها.
